**RealSense**
Prima abilita la depth allineata:

```bash
ros2 param set /camera/camera align_depth.enable true
```

Verifica se vuoi:

```bash
ros2 topic list | grep aligned
```

Poi lancia:

```bash

Output salvato in:

```

**Frequenza RealSense**
La camera pubblica a circa `30 Hz`, ma lo script non salva tutti i frame: salva con un timer ROS alla frequenza scelta da:

```bash
--capture_hz
```

Default:

```text
10 Hz
```

Quindi con:

```bash
python3 ~/pose_estimation_scripts/save_realsense_rgbd.py --capture_hz 10
```

salva circa 10 frame al secondo, prendendo l’ultimo RGB e l’ultima depth aligned disponibili in quel momento.

In più controlla che RGB e depth siano abbastanza vicini temporalmente:

```text
--max_rgb_depth_dt 0.05
```

cioè massimo 50 ms di differenza tra timestamp RGB e depth. Se la differenza è maggiore, quel frame viene saltato.

Se vuoi più frame puoi fare, per esempio:

```bash
python3 ~/pose_estimation_scripts/save_realsense_rgbd.py --capture_hz 30
```

Dato che la camera pubblica a 30 Hz, questo è circa il massimo sensato. Per iniziare io userei `10` o `15 Hz`; se il salvataggio regge bene, puoi salire a `30 Hz`.
